# Escreve Aí — versão beta estática

Este repositório contém o protótipo HTML integrado do Escreve Aí, preparado para publicação como site estático na Vercel.

## Publicação na Vercel
- Framework preset: Other
- Root Directory: `./`
- Build Command: deixar vazio
- Output Directory: deixar vazio/padrão sugerido
- Install Command: deixar vazio

O protótipo é demonstrativo. Recursos que dependam de IA remota, autenticação, banco de dados, pagamentos, upload persistente ou integração de impressão precisam de backend e configuração adicionais antes de uso em produção.
